# Repository instructions

## Pull requests

- When the user requests a change in a pull request, create and push the pull request without an additional confirmation round.
- Do not describe a pull request as mergeable, ready, or green based only on GitHub's technical mergeability or CI state.
- A pull request is ready to merge only after the Copilot review is green. Address all Copilot findings and verify the green review state before reporting readiness.
